What is this field?

Microsoft PowerPoint is an indispensable tool for visual communication, essential in almost every professional field. This program equips you with the skills to create compelling presentations, from basic slide design to advanced multimedia integration, culminating in the globally recognized Microsoft Office Specialist (MOS) certification.

Think of PowerPoint as your personal visual storyteller. Just as a chef uses various ingredients and techniques to create a memorable dish, you'll learn to use text, images, charts, and animations to craft presentations that inform, persuade, and engage your audience, making complex information digestible and impactful.

How the field grew

1987PowerPoint 1.0 released for Macintosh.
1990Microsoft acquires PowerPoint and releases Windows version.
1997Microsoft Office User Specialist (MOUS) certification program launched.
2003MOUS program rebranded to Microsoft Office Specialist (MOS).
OngoingRegular updates to MOS certifications for new Microsoft Office versions.
