What is this field?

This program teaches you to build dynamic, interactive mobile applications using the foundational languages of the web: HTML5 for structure, CSS3 for styling, and JavaScript for interactivity. You'll learn to leverage powerful libraries like jQuery and integrate advanced features through Web APIs, enabling your apps to perform tasks like accessing device capabilities or fetching real-time data.

Think of it like building a house that can instantly reconfigure itself to fit on any foundation, whether it's a small city lot or a sprawling countryside estate. Instead of building separate houses for iOS and Android, you'll create one versatile application that adapts seamlessly to different mobile devices and operating systems, reaching a broader audience with a single codebase.

How the field grew

2004The Web Hypertext Application Technology Working Group (WHATWG) forms, laying groundwork for HTML5.
2007The launch of the first iPhone sparks a revolution in mobile computing and the demand for mobile-optimized web experiences.
2014HTML5 becomes a W3C Recommendation, solidifying its role as the standard for web content and applications.
2015The concept of Progressive Web Apps (PWAs) emerges, blurring the lines between web and native mobile applications.
