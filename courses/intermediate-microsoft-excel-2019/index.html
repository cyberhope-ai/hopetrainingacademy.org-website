What is this field?

Microsoft Excel 2019 is a powerful spreadsheet application used across virtually every industry for organizing, analyzing, and visualizing data. This intermediate training builds upon foundational knowledge, introducing you to sophisticated functions, advanced data management tools, and automation features that streamline complex tasks.

Think of Excel as a super-smart digital ledger and calculator combined, but with the added power of a data scientist's workbench. It allows you to not only store numbers but also to perform intricate calculations, identify trends, create compelling charts, and even automate repetitive processes, transforming raw data into actionable insights.

How the field grew

1985Microsoft Excel first launched for the Macintosh.
1987Excel for Windows 2.0 released, quickly becoming a dominant spreadsheet application.
2007Major interface overhaul with the introduction of the Ribbon, enhancing usability.
2019Microsoft Excel 2019 released, featuring new functions, chart types, and Power BI integration.
