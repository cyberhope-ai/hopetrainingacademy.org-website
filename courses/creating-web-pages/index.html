What is this field?

Creating Web Pages is your foundational step into the world of web development, teaching you the core language that structures every website you visit. This program demystifies HTML (HyperText Markup Language), empowering you to build the essential framework of web content, from text and images to links and forms. It's the crucial first skill for anyone looking to design, develop, or even just understand how the internet works.

Think of HTML as the architectural blueprint and structural frame of a building. Just as a blueprint dictates where walls, doors, and windows go, HTML defines the elements and layout of a webpage. Without this fundamental structure, a website would be an unorganized pile of content. Mastering HTML allows you to lay this essential groundwork, preparing you to add styling and interactivity later.

How the field grew

1991Tim Berners-Lee introduces the first public description of HTML.
1995HTML 2.0 is published, establishing the first standard for web markup.
1997HTML 4.0 becomes a W3C Recommendation, introducing more advanced features.
2014HTML5 is finalized as a W3C Recommendation, bringing modern web capabilities.
