How the field grew

1984Cisco Systems founded, pioneering multi-protocol routers
1990sIntroduction of Cisco certifications, establishing industry standards for networking professionals
2000sExpansion of enterprise networking solutions, focusing on scalability and security
2010sEvolution towards software-defined networking (SDN) and automation in enterprise environments
2020Revamped CCNP Enterprise certification, emphasizing core technologies and specialization

What the career pays

Computer Network Architects design and implement complex data communication networks, including local area networks (LANs), wide area networks (WANs), and intranets. They ensure network security, efficiency, and reliability, often integrating new technologies and managing network upgrades.

$79,840entry
$129,720median
$177,690experienced

Source: U.S. Bureau of Labor Statistics, Computer Network Architects (SOC 15-1245)

Inside the course, module by module

01
Core Enterprise Network Technologies (ENCOR)

Campus architecture, device fundamentals, VLANs, STP, EtherChannels, inter-VLAN routing, FHRP.

02
Advanced Routing and Network Services

OSPFv2, EBGP, NAT, Multicast, GRE, IPSec VPNs, VRF, NTP, Syslog, SNMP, NetFlow, SPAN, IPSLA.

03
Network Security and Automation

Device access control, AAA, ACLs, CoPP, Next-Gen Firewalls, SD-Access, SD-WAN, DNA Center, data formats, NetConf/RestConf, Python.

04
Enterprise Wireless Network Implementation (ENWLSI)

Securing and troubleshooting wireless network infrastructure (WLCs, APs), configuration management via Cisco DNA Center/Prime Infrastructure.

05
Secure Client Connectivity and QoS

Implementing and troubleshooting 802.1X authentication, AAA services, Cisco CMX, and QoS in wireless networks.

06
Advanced Wireless Network Services

Implementing and troubleshooting location services, analytics, and wireless spectrum management.

Frequently asked questions

Do I need a college degree to enroll in this program?

No, a college degree is not required. This program focuses on practical skills and industry certifications, which are highly valued by employers in the IT sector.

Does this program include exam vouchers for the certification exams?

Exam vouchers for the current Cisco CCNP Enterprise certification exams (ENCOR and ENWLSI) are purchased separately and are not included with this training program.

How long will it take to complete this career training program?

This self-paced program includes 95 course hours. The total time to completion will vary based on your individual study schedule and prior experience.

Which Cisco CCNP Enterprise certification exams does this program prepare me for?

This program thoroughly prepares you for both the current Cisco CCNP Enterprise core exam (ENCOR) and the current Cisco CCNP Enterprise concentration exam (ENWLSI).

What kind of job can I get after completing this program?

Upon successful completion and certification, you'll be prepared for roles such as Network Architect, Senior Network Engineer, Wireless Network Engineer, or Network Consultant, among others.
