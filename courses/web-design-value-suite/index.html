What is this field?

Web design is the art and science of creating websites. It encompasses various disciplines, including web graphic design, user interface (UI) design, user experience (UX) design, authoring (HTML, CSS), and proprietary software. A web designer's role is to craft the visual aesthetics and usability of a website, ensuring it is both appealing and functional for visitors across different devices.

Think of web design like architecture for the internet. Just as an architect designs a building's structure, layout, and appearance to be functional and beautiful, a web designer plans and constructs the digital spaces we navigate daily. They ensure the 'rooms' (pages) are easy to find, the 'decor' (visuals) is engaging, and the 'doors' (links) work smoothly, creating a pleasant and efficient experience for every visitor.

How the field grew

1990Tim Berners-Lee invents the World Wide Web, laying the foundation for modern web design.
1993The release of Mosaic, the first graphical web browser, makes the web accessible to a wider audience.
1995JavaScript is introduced, enabling dynamic and interactive web content beyond static pages.
1996Cascading Style Sheets (CSS) are developed, separating content from presentation for more flexible design.
2014HTML5 and CSS3 become W3C recommendations, standardizing modern web development practices.
