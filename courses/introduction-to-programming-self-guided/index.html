What is this field?

Programming is the art and science of instructing computers to perform tasks. It involves writing precise sets of instructions, known as code, that a computer can understand and execute. This foundational skill is essential for creating everything from websites and mobile apps to complex software systems and video games.

Think of programming like teaching a robot to make a sandwich. You can't just say 'make a sandwich'; you need to break it down into tiny, explicit steps: 'pick up bread,' 'open jar of peanut butter,' 'spread peanut butter on bread.' Learning to program is learning how to give these detailed instructions to a computer, allowing you to build your own digital tools and applications.

How the field grew

1940sFirst electronic digital computers and early programming languages emerge.
1950sFORTRAN and COBOL revolutionize scientific and business computing.
1970sC language developed, becoming a cornerstone for operating systems and applications.
1990sRise of the internet and languages like Java and Python for web and general development.
2000s-PresentContinued evolution with mobile, AI, and cloud computing driving new programming paradigms.
